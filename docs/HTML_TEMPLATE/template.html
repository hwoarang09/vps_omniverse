개요

이 문서는 vps_omniverse 의 레일 겹침 정리를 USD 레이어 합성(LIVRPS)으로 구현한 내용을 정리한다. 이 단락은 템플릿 예시이기도 하다 — <h2> 가 1단계, <h3> 가 2단계 제목이고 번호는 자동이다.

핵심 아이디어

겹치는 레일을 "숨기지" 않고, base 레이어엔 raw 2줄을 전부 두고 별도 line_cut.usda 가 invisibleIds 로 비파괴 오버라이드한다.

  • base.usda raw 2줄 지오메트리 전부
  • line_cut.usda over /World/Rails { invisibleIds }
  • composed.usda subLayers=[line_cut, base] 정적 stitch

빌드 파이프라인

빌드타임 스크립트(컴파일러 같은 것). 앱 런타임 아님.

데이터 흐름

input/fab_map/*.map │ build_base.py ──► out/base.usda │ build_line_cut.py ──► out/line_cut.usda out/composed.usda ◄ 정적 stitch

실행

cd converter
python build_base.py     ../input/fab_map ../out/base.usda
python build_line_cut.py ../input/fab_map ../out
