개요

exts/ 는 런타임 코드다. 빌드타임 변환기(converter/, 순수 usd-core)가 구워낸 USD 를 Omniverse Kit 안에서 열어 실시간 시각화·조작하는 Kit 확장(extension) 두 개로 구성된다. 변환기와 달리 여기서만 omni.* API 를 쓴다.

  • vps.live.viz MQTT 로 받는 차량 위치를 PointInstancer 로 실시간 렌더
  • vps.rail.tools 레일 색 railColor variantSet(realistic/debug) 토글 UI

VPS(Three.js) 대응: Worker → SharedArrayBuffer → useFrame → InstancedMesh 흐름이 여기선 MQTT → 위치 버퍼(dict) → update tick → PointInstancer.positions 로 매핑된다 (extension.py:4-6).

실시간 차량 파이프라인

핵심은 스레드 분리다. paho-mqtt 콜백은 네트워크 스레드에서 도는데, USD 스테이지 편집은 메인(앱) 스레드에서만 안전하다. 그래서 수신 콜백은 버퍼 적재만 하고, 실제 USD 쓰기는 omni.kit.app update 콜백에서 flush 한다 (extension.py:8-11).

네트워크 스레드 — 버퍼 적재만

_on_message 는 USD 를 만지지 않는다. payload 를 파싱해 차량별 시간순 샘플 (t, x, y, rot, spd) 을 _buf 에 append 하고, JobState 는 _job 에 최신값으로 덮는다 (extension.py:212-244). 동시에 메시지 도착 간격으로 시뮬 배속(_sim_rate)을 EMA 로 추정한다 (extension.py:247-257).

메인 스레드 — 보간 후 flush

_on_update 는 앱 update event stream 에 구독되어 매 프레임(약 60fps) 돈다 (extension.py:101-105, 260). 렌더 시점은 최신 sim-time − 렌더지연 (RENDER_DELAY_MS = 3000.0, extension.py:53)을 추종하며, 안정적 _sim_rate 로 등속 전진한다 (extension.py:280-291).

  • 차량별로 rt(렌더 sim-time)를 감싸는 두 샘플 a/b 를 이진탐색으로 고름 (extension.py:303-319)
  • cubic Hermite 보간: 두 샘플의 속도벡터 spd·(cos rot, sin rot) 까지 존중해 가감속이 부드럽다 (extension.py:321-338)
  • 회전은 각도 최단경로 보간(170°→-170° wrap 방지) (extension.py:339-341)
  • 전 차량 일괄 numpy 연산 → Vt 배열로 변환, 차량당 Gf 객체 생성 최소화

최종적으로 PointInstancer 의 세 속성을 한 번에 갱신한다 — Positions / Orientations(쿼터니언) / ProtoIndices (extension.py:358-360). 그 후 rt − 2·DELAY 보다 과거 샘플을 트림한다 (extension.py:362-373).

차량 JobState 색상

OHT(차량) 형상에서 레일에 걸쳐진 대차(뚜껑)만 JobState 색으로 칠해 "픽업하러 가는 놈 / 드롭하러 가는 놈 / 대기 중인 놈"을 멀리서도 구분한다. 나머지(본체·FOUP·바퀴)는 고정색 (extension.py:55-59, 147-187).

실행 방법 두 가지

(a) 개발/시연 — 외부 Kit 앱을 런타임 호스트로

kit-app-template 등 기존 Kit 앱을 그대로 호스트로 쓰고, 확장 검색 경로에 exts/ 를 추가해 확장을 켠다. apps/ 가 비어 있어도 된다 (apps/README.md:5).

(b) 배포 — 자급형 .kit 앱 스캐폴딩
  1. kit-app-template 에서 repo template new 로 베이스 앱 생성 (apps/README.md:8)
  2. 생성된 .kit 의 [settings.app.exts.folders] '++' 에 exts 경로 추가 (apps/README.md:9)
  3. [dependencies] 에 "vps.live.viz" = {} 추가 (apps/README.md:10)
  4. 그 .kit 을 apps/ 에 복사해 버전관리 (apps/README.md:11)

확장이 켜질 때 의존성(omni.usd, omni.kit.pipapi, omni.ui)이 함께 로드되고, vps.live.viz 는 [python.pipapi] 로 paho-mqtt 를 런타임 설치한다 (vps.live.viz/config/extension.toml:11-22).
