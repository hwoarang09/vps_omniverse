프로젝트 개요vps_omniverse 가 무엇이고 어떻게 구성되어 있는가 — 입문

이 프로젝트는 무엇인가

vps_omniverse 는 VPS(AMHS 시뮬레이터)의 맵을 OpenUSD 로 변환해 NVIDIA Omniverse(Kit)에서 시각화하고 실시간 렌더하는 프로젝트다. 동시에 OpenUSD 학습과 NCP-OUSD 자격증 대비를 겸한다. (근거: CLAUDE.md 머리말)

  • 입력 — VPS 의 AMHS 맵 데이터(.map): 노드·엣지·루프·스테이션.
  • 변환 — 맵을 OpenUSD 씬(.usda)으로 빌드.
  • 출력/소비 — Omniverse Kit 확장에서 레일·스테이션 렌더 + MQTT 실시간 차량.

독자 기준: 이 프로젝트 개발자(=사용자). VPS(Three.js) 경험이 있다는 전제로, 해당 개념과 대조하며 설명한다.

핵심 철학 — 빌드타임과 런타임의 분리

프로젝트는 두 세계로 깔끔히 갈린다. 이 분리가 전체 구조를 이해하는 열쇠다. (근거: CLAUDE.md §1)

빌드타임: converter

converter/ 는 맵→USD 변환기다. 순수 usd-core(pxr) 만 쓰고 Omniverse 가 필요 없다. 컴파일러처럼 한 번 돌려 .usda 결과물을 만들어 두는 빌드타임 단계다(앱 런타임 아님).

런타임: exts

exts/ 는 Omniverse Kit 확장(omni.* API)이다. 빌드된 USD 를 열어 렌더하고, MQTT 로 들어오는 차량 위치를 실시간 반영한다. 변환기와 코드가 분리되어 있다. (근거: 실제 디렉토리 exts/vps.live.viz, exts/vps.rail.tools)

왜 나누나 변환기를 Omniverse 비의존으로 유지하면, CI/CLI 어디서든 usd-core 만으로 USD 를 재생성할 수 있고, 무거운 Kit 런타임은 "보여주는" 일에만 쓴다. VPS(Three.js)로 치면 "에셋 빌드 스크립트"와 "뷰어 앱"을 나눈 것.

전체 데이터 흐름

큰 흐름은 빌드타임 → USD 레이어 → 런타임 세 단계다. (1) 빌드타임에 입력 맵을 순수 usd-core로 두 레이어로 굽고, (2) line_cut이 base 위에 합성돼 composed.usda가 되며, (3) 사람이 그 stage를 열면 exts가 붙어 실시간으로 렌더한다. 각 단계 상세는 아래 전용 문서로 넘기고, 여기서는 단계별 그림으로만 본다.

레이어 합성(LIVRPS)·변환 파이프라인·런타임 동작의 세부는 이 개요에서 다루지 않는다. 각각 usd-composition, converter, runtime 문서를 참고.

폴더 구조

리포지토리 최상위 디렉토리와 각 역할. (근거: CLAUDE.md §1 + 실제 디렉토리 트리)

경로구분역할
converter/ 빌드타임 맵→USD 변환기(순수 usd-core/pxr). mapio.py(파싱) → geometry.py(기하·hide) → usd_build.py(USD prim) → build_base.py/build_line_cut.py(레이어 빌드).
exts/ 런타임 Omniverse Kit 확장. vps.live.viz(실시간 MQTT 차량 등), vps.rail.tools(레일 도구).
input/fab_map/ 입력 맵 데이터, 확장자 전부 .map: nodes·edges·loops·station· station_body·vehicles.
out/ 생성물 변환 결과(gitignore). base.usda·line_cut.usda· composed.usda. composed.usda 만 git 추적 — 여는 건 이것.
docs/ 문서 문서 모음. HTML_TEMPLATE/template.html(문서 템플릿), html/(생성된 HTML 문서), 그 외 메모/계획.
apps/ 앱 Kit 앱 관련(현재 README.md).
tools/ 도구 보조 스크립트. 예: mock_vehicle_publisher.py(MQTT 차량 모의 발행).

빌드 / 실행

변환은 빌드타임 스크립트다. 전용 파이썬(pxr 설치됨)으로 converter/ 안에서 실행한다. (근거: CLAUDE.md §2)

USD 빌드

cd converter
<venv> build_base.py     ../input/fab_map ../out/base.usda
<venv> build_line_cut.py ../input/fab_map ../out

변환 파이썬(<venv>): /home/vosui/vosui/omniverse_test/.venv/bin/python.

보기

usdview ../out/composed.usda   # 합성 결과 (line_cut + base)
usdview ../out/base.usda       # raw 2줄만
