vps_omniverse 문서AMHS 맵 → OpenUSD → Omniverse 시각화 · OpenUSD/NCP-OUSD 학습 겸

소개

vps_omniverse 는 VPS(AMHS 시뮬레이터)의 맵을 OpenUSD 로 변환해 NVIDIA Omniverse(Kit)에서 시각화·실시간 렌더하는 프로젝트다. 빌드타임 converter/(순수 usd-core, Omniverse 불필요)와 런타임 exts/(Kit 확장)로 분리되어 있다.

핵심은 레일 겹침 정리를 USD 레이어 합성(LIVRPS) 으로 비파괴 처리하는 것 — base 엔 raw 2줄 전부, line_cut 이 invisibleIds 로 오버라이드한다.

문서

overview 입문
프로젝트 전반 — 목적, converter↔exts 분리 철학, 폴더 구조, 빌드/실행. 데이터 흐름(빌드타임 → USD 레이어 → 런타임) 3분할 다이어그램.
converter 빌드타임
맵 → USD 변환 파이프라인(mapio → geometry → usd_build → base/line_cut)과 hide·라인끊기 케이스(직선/CURVE_90/180/CSC/S, 실제 좌표 plot).
usd-composition 핵심
USD 레이어 합성(LIVRPS) — subLayers=[line_cut, base], over invisibleIds 비파괴 오버라이드, base/line_cut 인덱스 1:1 정합.
runtime 런타임
Kit 확장(exts) — MQTT 실시간 차량(PointInstancer), JobState 색(차량 형상), railColor variant 토글, Kit 3층 구조와 실행.
usd-learning 학습
USD 학습 노트 / NCP-OUSD 대비 — Layer·Composition·Prim·PointInstancer·VariantSet 개념을 이 프로젝트 사용처와 연결.

빠른 시작

빌드타임 변환(순수 usd-core). converter/ 안에서 실행:

cd converter
python build_base.py     ../input/fab_map ../out/base.usda
python build_line_cut.py ../input/fab_map ../out

# 보기 (합성 결과): usdview ../out/composed.usda
# raw 만 보기:        usdview ../out/base.usda

런타임(실시간 차량/레일색)은 Omniverse Kit 앱에서 exts/ 를 확장 경로에 추가해 사용한다. 자세한 건 runtime 문서.
